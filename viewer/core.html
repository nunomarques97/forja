Continuar no terminal

Na pasta do projeto, usa forja core resume para uma execução interrompida. Uma tarefa bloqueada precisa de forja core retry --task ID --why "motivo". Os limites e tentativas são preservados.

Novos projetos: forja core init, seguido de forja start --provider claude --goal "objetivo" (ou codex). A guarda recupera apenas execuções em curso cujo processo e trabalhador terminaram.


## FORJA

When the user asks to use FORJA for a request (for example "use FORJA to ..." or "usa a FORJA para ..."), asks how FORJA is doing, or asks to resume FORJA, do not implement anything yourself. Read `%USERPROFILE%\.config\kilo\command\forja.md` and follow it, with the user's request in place of `$ARGUMENTS`.
